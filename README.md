# ポッドキャストLP サンプル

このフォルダは、ポッドキャスト「若干余談ですが。」のランディングページサンプルです。

## 見る方法

`index.html` をダブルクリックするとブラウザで開けます。

インターネット公開前の確認用として、そのまま仲間に共有できます。

## 入っているもの

- `index.html`: ページ本体
- `styles.css`: 見た目の設定
- `podcast-icon.jpg`: 番組アイコン画像

## 差し替えるところ

配信ページやSNSのURLを変える場合は、`index.html` 内の該当URLを差し替えてください。

エピソード欄は、Notionの「Podcast Episode 管理」を元に更新します。
第2回以降は、配信タイトルと公開URLが確定したものだけサイトに掲載する運用がおすすめです。

現在入っているリンク:

- Spotify
- YouTube
- X
- Instagram
- Facebook
- note

準備中として表示しているもの:

- Apple Podcasts
- Amazon Music

## 共有方法

このフォルダごと共有するか、同梱の `podcast-landing-sample.zip` を送ってください。

相手はZIPを展開して `index.html` を開くだけで確認できます。
